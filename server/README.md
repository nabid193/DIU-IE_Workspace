# Backend setup

See the root `README.md` for the clean-start instructions.

Important:
- Run `npm run db:setup` against the new Neon database before creating the first Admin.
- Run `npm run admin:create` once per fresh database.
- A valid email is accepted; `@diu.edu.bd` is recommended but not required.
- New passwords require 8–128 characters, uppercase, lowercase, a number, and a special character.
- Configure Resend for production password-reset emails.
